# Agro GFI — Gestão de Fazenda Inteligente

Toda a gestão da sua fazenda em um único lugar. Controle a lavoura, a pecuária, o financeiro, o estoque, as máquinas e tenha uma assistente de IA para consultar informações e apoiar suas decisões.

## Módulos

- Lavoura: talhões, safras, culturas, colheita e mapa das áreas
- Pecuária: lotes, pesagens, sanidade, ordenha e alimentação
- Financeiro: receitas, despesas, parcelamentos e orçamento da safra
- Estoque: entradas, lotes e consumo FIFO
- Máquinas: horímetro, abastecimentos e manutenções
- Relatórios e assistente de IA

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desenvolvimento local

```sh
# Clonar o repositório
git clone <YOUR_GIT_URL>

# Entrar na pasta do projeto
cd <YOUR_PROJECT_NAME>

# Instalar dependências
npm i

# Rodar o servidor de desenvolvimento
npm run dev
```
